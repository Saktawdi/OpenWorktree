OpenWorktree 内测版 · 使用说明
================================

一、环境要求
  1. Windows 10 / 11（64 位）
  2. Java 17 或更高版本（命令行输入 java -version 能看到版本号即可）
  3. Git 已安装并可在命令行使用（本产品通过真实 git 操作仓库）

二、启动
  双击 start_web_windows.bat：
    · 首次运行会自动生成 config\gate.toml 配置与 data\ 数据目录；
    · 随后启动后端服务（127.0.0.1:18080）并自动打开浏览器；
    · 「OpenWorktree」命令行窗口是后端进程，使用期间请勿关闭，报错也会显示在这里。

三、登录
  浏览器打开后先输入访问令牌（token），二选一：
    · 打开 data\gate-home\web-token 文件，复制其中内容；
    · 或在后端窗口里找 GATE_WEB_TOKEN=... 一行，复制等号后面的值。

四、配置审查引擎（可选）
  未配置引擎时系统可正常浏览，审查相关预检会跳过。
  进入「设置中心」配置 LLM Provider（API Key 加密落库）与引擎后即可跑完整的
  工单驱动开发流程。

五、数据与卸载
  · 所有数据（数据库、工单克隆、审计日志、token）都在本目录 data\ 内；
  · 备份/迁移：直接拷贝整个文件夹即可；
  · 卸载：删除文件夹即可，不会写入注册表或系统目录。

六、常见问题
  · 提示端口被占用：编辑 config\gate.toml，修改 [web] 下的 port（如 18081），
    保存后重新运行 start_web_windows.bat；
  · 双击后窗口一闪而过：通常是未安装 Java 17+，或 java 不在 PATH；
  · 忘记 token：直接查看 data\gate-home\web-token。

问题反馈请附上后端窗口的完整报错信息。
