# 项目走读报告：local-git-ticket-system

## 一句话定位

**一个「CLI 无关」的本地 Git 提交门闸层（gate）**——未经审核的代码无法经 git 协议进入权威 git 历史，闸门在 bare 库的 `pre-receive` hook 接收端强制生效，并配有一个 SQLite 持久化的六边形架构后端与一个 Vue3 Web 操作台。

---

## ① 背景与目标

本项目原立项为"一套本地 Git 工单系统"，经调研收窄定位于**提交闸门层**：核心闭环为「建工单 → 预提审（固化不可变 `tree_hash`）→ 审核（锚定 tree）→ 通过 → 发布（commit-tree + push）」。随后本迭代又补上了 **Web 操作台（gate-web 后端 + gate-web-ui 前端）** 与 **agent 会话编排**。

威胁模型被诚实界定：防的是"走捷径的错误/无意绕过"（例如模仿文档里现成 push 命令的 LLM），而**不隔离**同 OS 权限持 shell 的对手——这类对手只提供**事后可检测**手段（hook 哈希、reflog、哈希链审计日志）。

---

## ② 技术栈与架构

### 技术选型（D5–D8 定案）
- **Java 17 + Spring Boot**，核心模块用 `WebApplicationType.NONE`（无 web），六边形多 Maven 模块。
- 审核引擎 **`dshills/prism` 单选**；**权威 Git 路径禁 JGit**，一律经 `ProcessRunner` 调真实 git（ADR-1）。
- 接入 **MCP stdio 优先**；LLM 经 **newapi 网关**（`https://newapi.sakta.top`）中转，不装 Ollama（ADR-9），对外只暴露 `(provider_id, model_name)`。

### 分层约束（ArchUnit 强制）
- **单向依赖：`gate-ports → gate-domain → JDK`**。domain 零 Spring/JGit/java.sql，纯 POJO/record；adapters 互不可见。
- fail-closed 靠 **sealed 类型契约**而非纪律；SQLite/WAL；通过退出码表（0/10-13/20-22/64/70）表达失败。
- approval 绑定 `(ref, old, new, tree)` 且**单次消费**（推翻原"tree 即令牌"方案）；agent 仓库强制独立 clone（禁链接 worktree，封绕过 B14）。
- 本迭代 gate-web 用 **JDK 内建 `com.sun.net.httpserver` + AuthFilter**，不用 Javalin/Spring-Web；前端 Vue 3 + TS + Vite + Naive UI + Pinia + Monaco。

## ③ 各模块职责

### gate-domain（纯领域层，`gate.domain.*`）
12 子包：`git`（ObjectId/RepoRef）、`snapshot`（快照+完整性审计）、`review`（评审证据模型）、`blob`（BlobRef 大对象引用）、`ticket`（工单聚合）、`publish`（发布 write-ahead）、`audit`（哈希链审计）、`policy`（决策/授权铸造）、`error`、`config`、`task`、`session`（Agent 会话）。

核心模型：`Ticket`（record 工单聚合）、`GatePolicy`（唯一裁决 `decide(...)`）、`PublishAuthorization`（仅 GatePolicy 可铸造）、`PublishIntent`（write-ahead）、`ApprovalGrant`（四元绑定）、`Snapshot`、sealed `ReviewEvidence`（EngineReport/EngineFailure）、`Session`/`GateTask`/`AuditEvent`。

### gate-ports（`gate.ports` 单包）
只声明出向依赖接口，分四类：
1. 仓储（8 个 `*Repository`）；
2. Git/进程/拓扑服务（CommitPublisher、SnapshotCapture、RefObserver、PreflightChecker）；
3. 资源能力（LockManager、DbTransactionRunner、TaskRegistry、Clock）；
4. 评审/Agent 服务（ReviewEngine、ReviewEngineFactory、AgentSessionPort）。

`ReviewEngine.review(...)` 永不抛异常，失败以值（EngineFailure）表达用于 fail-closed。

### gate-application（扁平单包 `gate.application`）
应用用例编排层，CLI/MCP 驱动的唯一入口。`GateService`（接口）+ `GateServiceImpl`（唯一实现，5 个用例，658 行），另有 `MetricsService`/`H1Verdict`（成本度量旁路）与 `EvidenceCodec`/`MiniJson`（无 Jackson 序列化）。经 `gate.ports` 的 16 个接口解耦；`DbTransactionRunner` 界定事务且不跨 git 调用（I3）；失败统一抛带 `GateErrorCode` 的 `GateException`。

### gate-adapters（`gate.adapters.*`，实现全部 ports）
- **process**：`ProcessRunnerImpl.java` 唯一真正拉起外部进程的执行器——用 `ProcessBuilder` 但把 stdout/stderr **重定向到临时日志文件而非管道**（避免子进程填充管道缓冲区导致 `waitFor(timeout)` 永不触发）；超时时先 `process.descendants().forEach(destroyForcibly)` 强杀进程树再杀自身（防 git 子进程占用句柄）。
- **io/git**：`FsUtil`（先 `setWritable` 再删只读文件树，适配 Windows `.git/objects`）；`GitCli`（不引 JGit 的薄共享前端，`must()` 响亮失败）+ `GitCliSnapshot/Publisher/RefObserver/TopologyInitializer`。
- **store**：SQLite 经 JDBC/JdbcTemplate（刻意不用 JPA），`SqliteDataSourceFactory` 设 WAL/synchronous=FULL/foreign_keys/busy_timeout 四 PRAGMA 并 Flyway 迁移（V1–V4）；`Jdbc*Repository` 访问 ticket/provider/token-SHA256/credential/presubmit/review_result/publish_intent/session 等表；`SpringDbTransactionRunner` 只收 Supplier，禁止混入 git 调用。
- **audit/blob/approval/lock/hook**：`HashChainAuditLog`、`FsBlobStore`/`FsApprovalStore`、`FileChannelLockManager`、`FileHookInstaller`（生成安装 `pre-receive` hook）。
- **装配**：Spring 仅作薄壳，`GateComponents.java`/`WebComponents.java` 用纯构造器注入手工装配对象图。

### gate-cli（picocli）
`RootCommand.java`（`@Command(name="gate", subcommands=...)`），共享选项在 `BaseCommand.java`：`-c/--config` 必填 gate.toml、`--git` 指定 git 二进制。

### gate-web（后端 Web 操作台）
直接用 JDK `com.sun.net.httpserver.HttpServer`（ADR-8），路由集中在 `ApiRoutes.java`（`/api/*`）：
- 基础：`/health`、`/auth/verify`、`/status`（门禁状态投影）、`/reconcile`（对账）、`/metrics`、`/metrics/h1`、`/config`（脱敏）、`/providers`。
- Ticket：`/tickets`、`/tickets/{no}/presubmit`、`/review-result`、`/presubmit/{round}/diff`。
- S2 异步：`/tickets/{no}/review`、`/publish`（202+task_id，`TaskRunner` 单线程执行）、`/tasks/{id}`、`/tasks/{id}/events`（SSE）。
- S3/S4：`/agent-configs` CRUD、`/tickets/{no}/sessions`、`/sessions/{sid}/messages`、`.../abort`、`/sessions/{sid}/events`（SSE）。

安全由 `AuthFilter` 完成：Host/Origin 白名单（防 DNS rebinding，fail-closed）+ `Authorization: Bearer` HUMAN 域 token（SSE 额外接受 `?token=`，日志脱敏）。

### gate-web-ui（前端）
**Vue 3.5 + TypeScript + Vite 5 + Pinia + Vue Router 4 + Naive UI + axios**，测试用 Vitest + jsdom + @vue/test-utils + MSW。目录 `src/{api,components/ui,composables,router,stores,styles,types,utils,views}`；UI 为自研 G 系列组件。页面：LoginView、HomeView、TicketKanbanView、TicketDetailView、ReviewConsoleView、Session…（`src/views/`）。与后端经 `src/main/resources/static`（静态托管）和 dev 代理对接。
